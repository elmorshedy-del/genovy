## Minimal edit from the actual trained schema

Use this conversion:

- keep top-level `chapter`
- keep top-level `phenotypes.present / excluded / uncertain`
- keep top-level `ancillary_clinical_evidence`
- keep top-level `context_metadata`
- keep top-level `context_notes`
- keep `label`
- add `evidence_refs` to phenotype rows
- add `clinical_role` to phenotype rows
- add `qualifiers` to phenotype rows
- convert ancillary bucket string items into small objects with:
  - `finding`
  - `assertion`
  - `evidence_refs`
- keep `context_metadata` as strings
- add sibling `context_evidence_refs`
- add optional `source`, `source_url`, `source_date` to `chapter`

### Exact qualifier mapping from the old schema

- any age or timing detail

- any progression / recurrent / episodic / worsening / improving detail
  - `qualifiers.progression`
- any trigger detail like fever / exercise / lights
  - `qualifiers.trigger`
- any mild / severe / marked / profound detail
  - `qualifiers.severity`
- any refractory / responsive to treatment detail
  - `qualifiers.treatment_response`
- any left / right / bilateral / asymmetric detail
  - `qualifiers.laterality`
- any proximal / distal / focal / diffuse detail
  - `qualifiers.distribution`

- any shape / structural appearance detail
  - `qualifiers.morphology`

## Rules for Opus

- one phenotype finding per row
- no copied `source_quote`
- no copied `source_section`
- no synthetic paragraph or sentence location objects in output
- every phenotype row must point to `evidence_refs`
- every ancillary evidence row must point to `evidence_refs`
- every populated `context_metadata` key should have matching `context_evidence_refs`
- qualifiers stay free text
- use `clinical_role=complication` for outcomes/complications like `SUDEP` or `status epilepticus` when they are not primary syndrome-defining findings
- use `clinical_role=descriptor` when the item is a feature of another finding rather than an independent phenotype edge
